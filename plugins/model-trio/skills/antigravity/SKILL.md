# 请教 Antigravity

用 `mcp__plugin_model-trio_peers__antigravity` 工具。Gemini 点子多、文案好，但粗心：它只读、只给意见，它说的事实要你对照代码核实后再用。它看不到当前对话，背景要写进 `task`；追问用 `conversation_id` 续接。

- **独立方案**。大方案（架构怎么定、数据怎么存、要不要长期绑定某个服务、系统整体怎么改）自己出一份，并请它独立出一份：`task` 里只给用户的原话和必要背景，不给自己的草稿和倾向。两份由你合并：有分歧以代码和实际数据为准，它标「推测」的先核实。合成一份给用户，写明两份一致的、采纳了它的、不采纳的和理由；两边都有道理、定不下来的，原样摆给用户拍板。
- **文案和交互顾问**。界面文案和交互自己先做一版，再请它改一遍：告诉它这一页是给谁用的、要让人做成什么、现在的文案和交互。它的修改由你对照功能实际怎么用核实后采纳。只改几个字的不用。
- 模型默认用 Antigravity 自己的设置，用户指定了才传 `model`。
- Antigravity 出错或额度用完时告诉用户，不自行换别的办法代替。
