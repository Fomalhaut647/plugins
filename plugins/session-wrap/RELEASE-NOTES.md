# session-wrap 版本说明

## v0.4.0

- 第 1 步不再调用 neat-freak，只把本会话改动涉及的文档改到和代码一致，不再每次通读全部文档。
- 提交前先收齐子会话的改动：还在跑的等它结束，在自己工作树里改的把分支合进本会话的分支（调用本 skill 就算同意合并），直接改在本工作区的算本会话的改动。
- 删掉「清理废弃的分支和工作树」这一步，改为隔几天单独开会话清理。

## v0.3.0

- 新增一步：合并或推送进 main 后，用 `gh issue close` 关闭本会话修复的 issue，评论里注明修复所在的 PR 或提交；没修完的不关，在报告里说明。

## v0.2.2

- 启用条件放宽：原话里出现 session-wrap 这个词即可（连字符、大小写不算不同），不再必须说「调用」。

## v0.2.1

- README 的前置条件注明 `neat-freak` 可从本 marketplace 安装。

## v0.2.0

- 开 PR 后在本轮里用 `gh pr checks --watch` 等 CI 跑完，不再结束本轮去报告「在等 CI」：通过就直接合并并继续收尾，失败就自己修好再推。

## v0.1.0

从个人 dotfiles 迁入，通过 `fomalhaut647-plugins` marketplace 首次发布。

- 新增 skill `session-wrap`：整理文档、提交推送、开 PR 合并、清理分支和工作树、归档会话；可选合并前 / 多轮 code-review 审查。
