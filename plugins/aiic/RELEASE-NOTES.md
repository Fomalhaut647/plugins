# aiic 版本说明

## v0.1.0

初版，通过 `fomalhaut647-plugins` marketplace 首次发布。

- 新增 skill `deep-thinking`：用「四次思考」（直觉答案 → 广度与深度 → 地域与时间跨度 → 抽象高度）分析一个问题，附万州公交车坠江事故的完整示范。
- 新增 skill `demand-analysis`：按「用户 × 场景 × 动机」分析产品需求，评估需求侧关键要素、供给侧壁垒及 Why NOW / Why ME，并设计验证；附分析工作表和课程依据。
- 新增 skill `market-sizing`：按「年规模 ＝ 广度 × 强度 × 频度」测算或审计市场规模；附口径与计算指南、课程案例、测算工作表，以及一个只用 Python 标准库的计算脚本和它的测试。
