# 交给 Codex

用 `${CLAUDE_SKILL_DIR}/codex.sh` 把任务交给本机的 Codex 命令行，选项和退出码写在脚本开头。任务书写成文件，和运行目录一起放在草稿目录。脚本把 Codex 限制在沙箱里，给任务书追加固定规矩（不提交不推送、不碰密钥、汇报和发现的写法），屏幕上只打印结果和汇报。

- **三种模式**。`review` 是 Codex 自带的审查模式，只读：任务书写审查范围（如未提交的改动，或 `<基线>...HEAD`）和希望它重点看的地方，有验收标准的也写上。`read` 只读，用于调研或要第二意见。`code` 让它写代码，只能写 `--cd` 那个工作副本，不提交。
- **在后台运行**。分派命令用 Bash 的 `run_in_background`，结束时会唤醒你，期间不轮询。用户问进度时用 `--progress`，要中途停下用 `--stop`。
- **默认参数** `--model gpt-6.1-sol --effort xhigh --fast on`，用户指定了就按用户的。
- **审查你自己的改动时**，逐条对照代码复核 Codex 的发现：不成立的丢掉并说明理由，成立的报告给用户。只审一轮，修完不自动再审。
- **Codex 出错或额度用完**时告诉用户，不自行换别的办法代替。
