# neat-freak

> [中文版](README.md)

End-of-session knowledge cleanup: reconciles project docs, rule files (CLAUDE.md / AGENTS.md), agent memory, and workspace residue with what the code actually does, and audits whether project rules are really followed. [`session-wrap`](../session-wrap) uses it in step 1 to tidy docs.

## Source

Copied verbatim from `neat-freak` in [数字生命卡兹克](https://github.com/KKKKhazix)'s [khazix-skills](https://github.com/KKKKhazix/khazix-skills) repository (skill version 3.0.0, upstream commit `322346d`), only packaged as a plugin so it can be installed from this marketplace. The upstream evals suite is not included. The plugin version follows the upstream skill version.

## Installation

```
/plugin marketplace add Fomalhaut647/plugins
/plugin install neat-freak@fomalhaut647-plugins
```

## Usage

Say things like "tidy up docs", "sync up", "update memory", or "/neat". See [`skills/neat-freak/SKILL.md`](skills/neat-freak/SKILL.md) for the full text.
